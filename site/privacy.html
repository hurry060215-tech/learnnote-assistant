PRIVACY

隐私说明

LearnNote 是本地优先的视频学习助手。普通桌面工作流不需要 LearnNote 账号，也不会把任务上传到 LearnNote 运营的云服务。

本地保存

视频、字幕、音频、抽帧、笔记、模型缓存、任务记录和导出文件保存在用户选择的数据目录。Windows 客户端默认只在 127.0.0.1 启动本地服务。

浏览器扩展

用户打开侧栏、重新识别或主动发送时，扩展会检查当前页可访问的视频、iframe 和字幕。主动媒体网络捕获窗口最长 5 分钟，不持续录制或监听全部浏览活动。所需页面证据及登录 Cookie 只交给用户连接的本机 LearnNote 服务。

用于恢复识别结果的候选缓存与主动捕获窗口不同：缓存最多保存 120 项、最长 30 分钟，不保存 Cookie 或 Authorization 值。页面切换、标签页关闭或检测上下文重置后会清理。

外部服务

下载视频时会访问相应网页、媒体主机和 CDN。使用远程转写、文本模型或视觉模型时，所需音频、转写片段、问题或画面网格会发送给用户主动配置的提供商。本地 faster-whisper 转写不会向模型 API 上传音频。

API Key

网页工作台与 App 通过本机服务共用模型配置。Windows 和 macOS 使用系统凭据库，保存范围绑定到资料目录与模型地址；系统保存不可用时会明确提示仅本次运行有效，不写明文备用文件。 页面只读取连接状态，保存的 Key 不返回页面，也不写入任务 JSON、诊断或导出资料。

草稿与历史版本

未发送的助手输入保存在当前浏览器，按笔记分别保留，最多30份、每份1000字；发送成功或清空输入后移除。重新生成前的旧正文保存在任务目录，可预览和下载，不覆盖个人修订。清理浏览器站点数据可以移除草稿，删除任务时其历史文件随任务移除。

遥测与广告

个人主页的可选称呼保存在当前浏览器。本机 Token 用量记录保存请求时间、模型、服务域名、状态与服务商返回的用量，不保存提问、回答或 API Key，也不代表账号余额。主动打开 B 站在线视频来源时会访问官方外链播放器；可选语音模型仅在按需下载或明确使用本地转写时获取。

当前开源版本不包含广告、行为跟踪、产品分析或自动崩溃上报。

删除与分享

用户可以在客户端删除任务或清理数据目录。诊断与导出会隐藏已知敏感字段，但在公开分享前仍应检查标题、页面域名、字幕、截图和时间信息。

完整、可审计的英文政策见 GitHub 仓库中的 PRIVACY.md。
