# Repository guidance

Read [CONTRIBUTING.md](CONTRIBUTING.md) for development and validation rules.

For every UI page, dialog, or component change, read and follow the root
[design.md](design.md). It is the current workspace design contract, including its
reference-pending status. Reuse the existing semantic tokens and components,
preserve readable left-aligned content and reduced-motion support, and verify
affected states with actual browser screenshots. Update the contract alongside
intentional design changes; do not treat archived concept images as the current
implementation.
