# Local OCR and frame-cache acceptance, 2026-10-08

Scope: a verified increment for #149 on main `61f6c5d`, after integrating
the evidence/export increment. The epic stays open.

## Repaired contracts

- Frame-cache schema v2 includes media SHA-256, timestamp plan and extractor
  version. Replacing media with different bytes but the same size and mtime
  can no longer reuse old evidence frames. Hashing streams the file in bounded
  chunks; it adds one media read when checking this cache.
- OCR cache v2 validates engine, image digest, schema, boxes, finite confidence
  and canonical text. Malformed/stale caches are rebuilt. Cached content can
  never promote itself to verified evidence.
- Identical images reuse OCR while retaining each source timestamp. One failed
  frame preserves earlier successful frames, gives a partial result and safe
  retry notice, and exposes only the error class. Cancellation still propagates.
- Each line has an explicit conservative script/language hint, confidence and
  unreviewed status. Empty results are `no_text`; all OCR frames require review.
- ONNX Runtime platform telemetry is explicitly disabled before constructing
  the OCR engine. The order has a regression test.
- CI now installs the constrained optional OCR runtime and requires actual
  image recognition; an absent engine cannot silently count as a skipped pass.

## Executed verification

- Normal cloud environment: 691 backend tests pass, one optional OCR skip;
  100 script tests pass, two PowerShell-only skips; architecture/diff checks pass.
- Separate constrained OCR environment: all 10 OCR/cache tests pass, including
  the actual image recognizer, without skips. No shared test environment was
  modified. Production dependencies and runtime version pins are unchanged.
- `scripts/ocr-fixture-benchmark.py` ran behind the offline network guard on
  self-generated English, Chinese, code, formula, slide and low-resolution
  images. All six fonts/fixtures were available. First run made six local
  engine calls in 5.135 s; repeated run made zero calls in 0.001 s, retaining all
  source timestamps and unreviewed markers.
- Character similarity on those exact six inputs was respectively 1.000,
  1.000, 1.000, 0.714, 0.941 and 0.375. Formula and low-resolution recognition
  are visibly imperfect and remain unreviewed. These are fixture observations,
  not general OCR accuracy or a performance promise.

Run `python scripts/ocr-fixture-benchmark.py --output-dir build/ocr-fixtures`
after installing the existing optional OCR requirements. The JSON report lists
any missing platform fonts explicitly. No real course, URL, credential or
third-party model is used.

## Remaining original acceptance

OCR cache reuse is **not** evidence of a 50% reduction in remote vision calls
with unchanged factual coverage. That comparative benchmark remains open,
along with full long-video OCR resource budgets and remote-grid selection
acceptance. No remote vision call was made by this increment, and it does not
silently substitute OCR guesses for course claims.
