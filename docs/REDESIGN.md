# LearnNote 0.2.0 工作台重设计

## 目标与边界

本轮针对用户明确提出的界面杂乱、操作不连贯和笔记质量问题，重做默认应用入口、官网与 README。保留本地数据格式、媒体获取、转写、证据和打包底层；不把重写界面理解为清空用户资料。

默认页面不再加载旧版 app.js 和六层应用 CSS。它使用独立的 desk.js、desk-api.js 与 desk.css。旧版保存在 classic.html，通过设置中的专项工具入口访问。课程归档、范围学习、OCR 审阅及高级诊断暂未移植到新布局；这部分不宣称已重新设计。

## 主流程

- 一个新建入口：链接、本地文件或浏览器交接；整理偏好默认折叠。
- 左侧笔记列表，中间正文，按需打开原始来源。
- 视频时间戳和字幕点击定位；播放时高亮对应字幕。
- 直接编辑 Markdown，修改独立保存，原始笔记与来源证据不被覆盖。
- 乐观修订检查拒绝过期保存；离开时提示未保存正文或补充。
- 正文补充、Markdown 导出、基础复习、模型设置与深浅主题。
- 对已有视频可重新整理，生成新任务，保留旧笔记及修改。

## 内容整理

默认本地降级路径改为明确标记的字幕摘录，按时间和文本长度分段，只出现一遍原文；不再将同一句话复制到核心概念、易错点和复习等模板。专业旧模板保留兼容行为。

默认模型提示改为内容命名的主题结构，不要求最低字数、固定题数或统一空章节。文字路径使用带时间戳的字幕块，长输入逐块处理，某块失败时整体降级到完整摘录，不把缺失后半段的结果当作完整笔记。视觉合并路径仍需更大的真实材料基准。

这些改变消除了已知模板问题和首段截断，不代表已经通过真实模型准确率或学习效果评估。当前回归采用可复现合成材料和模拟模型；不将其展示成真实课程效果。

## 官网与说明

官网采用与应用一致的浅色阅读风格，移除重装饰和功能指标堆叠。效果区域明确为演示内容。所有下载入口指向 GitHub 实际 latest release，避免候选版尚未发布时链接到不存在的安装器。

README 按快速开始、输入路径、生成结果、隐私边界和开发运行组织。手机仅提供基本窄屏可用性，不承诺手机 App 或跨设备同步。
