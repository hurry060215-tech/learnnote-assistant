# 2026-10-08 云端回归与 CI 加固

基线：main `7c26264fdac8aa2f56a95d264a8976fefe3d2041`。

## 修复内容

- 本地 ASR：faster-whisper 1.2.1 调用 PyAV 19 已移除的 `metadata_errors` 参数，真实音频解码会失败。统一可选 ASR 依赖为 `requirements.asr.txt`，限制 PyAV `<19`，更新 Windows 安装/修复、Docker、健康提示和两种打包入口。
- 重复视频：只有来源为本地、媒体哈希和处理选项一致才复用任务，避免新选项被旧任务忽略。
- 文件名：保留长英文资料名扩展名，并为中文/emoji 文件名以及视频暂存前缀保留 UTF-8 字节空间。
- 字幕：相隔停顿的同一句话保留独立位置，重叠滚动字幕不缩短结束时间，倒置时间段被忽略。
- PDF：区别损坏文件、需要密码和缺少解析组件；扫描 PDF 的可选 OCR 流程保留。
- 个人修改：损坏结构或不一致的修订哈希返回可理解的 409，保留原文件，避免覆盖。
- 模型缓存：缺失/空文件不再继续显示已准备；损坏的 Hugging Face 引用可重新准备。非空权重内部完整性仍由实际加载检查。
- 网络诊断：LLM 事件包含本地配置失败、缓存命中，不能当成远程调用计数。pipeline-status 保留 remote_calls/local_only 字段但返回 null，并明确 remote_call_count_available=false；diagnostic_event_count 单独表示事件数。没有完整网络台账时，不声称任务仅在本地运行。
- 测试隔离：示例网站访问被替身替代，临时目录不再要求已运行过应用，平台断言及用户主目录写入已隔离。

## CI 的增量改进

新增 Ubuntu/Python 3.12 的实际 WAV 解码回归。它安装可选 ASR，并使用现有完整运行时锁作为约束，补齐 Linux 独有依赖约束；显式导入解码器后运行回归，不能因未安装 ASR 而悄悄跳过。模型保持离线，不下载权重，不访问付费模型。

原有 Windows 主 CI 保留完整测试和打包 smoke，新增依赖一致性检查，并确保每个 JavaScript 语法错误立即失败。没有放宽必需检查、删除失败测试或修改发布条件。

## 验证与边界

恢复后的云端代码重新执行完整后端、脚本、桌面测试以及真实 WAV 解码。当前环境为 Linux/Python 3.12；可选 OCR 引擎和 PowerShell 未安装，相应跳过必须单独报告。最终精确提交的 GitHub 检查才是合并依据。

此前真实测试还覆盖了 tiny CPU 语音识别、Uvicorn HTTP 上传/暂存 token/重复导入、字幕导出、个人修订冲突、Markdown/Word/PDF 内容回读、任务取消和混合队列。60 秒及 1 小时合成视频流程使用预置字幕和确定性总结替身，不能作为长时真实 ASR 或真实模型质量证据。

云浏览器无法打开该环境本地服务，因此未声称完成新一轮人工界面或原生扩展权限弹窗验收。用户登录态视频网站、付费模型、GPU、原生 Windows/macOS 安装升级仍未验证。所有测试材料为自制或公开模型数据，未使用私人凭据。
