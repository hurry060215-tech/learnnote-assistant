# LearnNote v0.2.19

## 本次修复

- 补齐扩展更新包的运行文件白名单；用实际发行文件验证完整安装，额外未审阅文件仍被拒绝。
- 修正 macOS 预览的媒体工具配置、路径比较及扩展文件打包。

- 切换资料或返回上一份资料的请求较慢时，新增的笔记和批注不会被迟到的响应静默清空。拒绝离开会保留当前内容与导航；未变化的已确认丢弃不会重复提示。
- 单个损坏或不可读的任务文件不会阻止客户端启动和健康任务恢复。原文件、任务代次与取消记录保留，相关任务等待单独处理；数据库错误仍明确报出。
- 后台刷新时点击“加载更多资料”会保留一次分页请求，使用新游标并在旧刷新完成后展示。重复点击合并，搜索变化取消旧请求。
- 扩展状态、下载、安装与校验使用扩展自身版本，支持客户端与扩展独立版本。
- 后续发布持续执行已有安装验收，避免版本递增时遗漏阅读、分页和来源导航检查。

## 安装与验证

客户端和随包扩展版本均为 0.2.19。正式发布要求从最终提交重新构建，完成新安装及官方 0.2.17 到 0.2.19 的覆盖升级、实际安装版功能检查和上传后下载校验。源码修复与旧安装包验收不代替本版安装验收。

使用 LearnNote-Setup-x64.exe 安装或升级；便携包为 LearnNote-Windows-x64.zip。构建提交、依赖清单和资产校验和随发布提供。用户资料和配置保留；损坏任务文件的隔离不等于自动修复其内容。GitHub 发布不会自动提交浏览器商店。

## 保留的边界

本版集中修复日常使用与恢复问题。语义证据验证、公式和低清 OCR、真实模型与长视频质量仍需独立评测。Windows 未配置签名凭据时仍为未签名包，macOS 分发仍按预览平台说明处理。
