# LearnNote 本地候选版本验收记录（2026-09-17）

本候选版本保持本地优先边界：没有新增联网检索服务、搜索密钥、外部搜索 API 或费用配置。模型调用仍沿用用户已经配置的模型连接；资料库搜索只读取本机已经索引的来源。

## 本轮已落地

- 普通视频总结默认关闭题目生成。`summary_depth` 只影响详略，不再强制 2/4/6-8 道题；`generate_questions` 只有用户明确勾选本次生成练习时才开启。无模型回退也采用“概述 → 核心要点 → 原文时间段”的无题目结构。
- 助手改为自动判断：选中笔记不再自动把所有问题路由为内容问答；只有明确提到当前笔记、字幕、原文或“这段讲什么”等意图才读取当前来源。普通知识问题走通用问答，明确资料库检索才走本地检索。
- 助手隐藏常驻 Skill 下拉框；来源显示为可识别的来源标签，Skill、模型、实际来源范围放到可展开的处理详情。快捷建议只在空会话显示，支持关闭单条、隐藏整组，并可在设置中恢复。
- 字幕引用提供主阅读区原文定位和“返回总结”。定位使用来源 ID 与时间范围，未找到精确字幕段时不猜测高亮；定位和 cue 点击不自动播放，播放保留为独立的视频控件操作。
- 新增学习空间 API 与入口。旧课程清单会幂等迁移为学习空间；空间只保存来源引用、目标、重点、每日复习量和题型，不复制普通笔记。资料、练习、复习计划三个视图共用现有 FSRS 卡片和评分记录；重复加入同一来源不会新增同一张卡片的 FSRS 记录；未归属卡片进入“已有复习”。
- 新增统一导出预览/导出接口：HTML、Word、PDF 共用结构化内容和排版配置。支持正文、个人补充、来源链接、时间点、图片、目录、完整字幕和学习空间练习的选择，以及字体、字号、行距、段距、页边距和方向。旧 Markdown/DOCX/PDF 调用保留。
- 修复 B 站字幕设置面板污染字幕：扩展端排除设置菜单、控件容器、重复 UI 标签和不在视频底部字幕区域的元素；background 与后端再次过滤旧扩展/历史 payload。真实字幕轨道和 DOM 字幕叶节点仍保留。

## 字幕问题的确定性根因

截图中的“背景不透明度、字幕大小、主字幕、恢复默认设置”等文字来自 B 站字幕设置面板。旧采集逻辑的 `looksLikeVisibleSubtitleElement()` 以 class/id/aria 中是否包含 `subtitle`、`caption` 或“字幕”为主要判断，且没有验证元素是不是字幕叶节点、是否位于视频字幕区域；因此设置面板里的每个选项都被当作同一播放时刻的字幕 cue。后端原本只能在任务处理后过滤，侧栏“原文预览”已经先显示污染结果。
