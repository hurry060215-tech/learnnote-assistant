# LearnNote v0.2.15

## 本次更新

- 统一阅读层级与响应式操作，保留侧栏状态，官网与当前工作区样式对齐。
- 增加明确触发的整篇与分章节校对，保留版本、恢复与草稿状态，避免把 AI 生成当成事实核验。
- 展示来源绑定的渐进文本、主题与视觉草稿，记录本次任务阶段；耗时与 Token 没有可靠数据时保持未知。
- 区分候选出处与支持证据，修复 Unicode 摘录和时间链接，尊重视觉模型图片数限制。
- 改善个人内容备份恢复、资料目录、任务取消与重试，提供有审阅和撤销边界的助手编辑及导出。
- 增加可恢复的本地屏幕字幕提取、完整过滤图谱导出及学习空间相关改进。

## 安装与版本

客户端与随包浏览器扩展均为 0.2.15。Windows 新安装使用 LearnNote-Setup-x64.exe，便携使用 LearnNote-Windows-x64.zip。本机资料和模型配置继续保留；升级前建议备份个人资料。

正式资产仅在同提交可靠性检查、自动化回归、安装及覆盖升级冒烟、上传后重新下载校验通过后公开。下载请核对 SHA256SUMS.txt 与 LearnNote-Build-Source.json。GitHub 发布不自动提交 Chrome Web Store，商店版本独立审核。

## 验证边界与已知限制

本版本整理已经合入的功能和修复，不代表全部开放 issue 已完成。自动化与合成媒体检查不能替代真实模型质量或真实课程验收；四小时真实视频、Word/WPS 原生布局、Chrome 权限矩阵、macOS 实机和完整产品验收仍未全部完成。不承诺秒提取、全部事实正确或固定生成速度。

Windows 没有配置 Authenticode 凭据时为未签名包，系统可能提示未知发布者。macOS 未签名、未公证构建仍属预览；不将其标为已完成原生验收。

## 维护者发布方式

已有版本标签可沿用 Desktop Release 的 release_tag 输入。尚无标签时，在同一工作流填写 release_tag=v0.2.15 和已审阅、CI 通过的完整 40 位 release_commit。工作流只构建这个提交，在完整门禁、打包和安装升级检查之后才创建缺失标签；已存在但指向不同提交的标签会使发布失败，不会覆盖。随后仍使用草稿上传、回下载校验再公开的原有流程。
