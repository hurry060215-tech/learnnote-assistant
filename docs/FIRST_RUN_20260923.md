## 实际路径发现与修复

1. **重复启动会误报成功。** 在隔离数据目录的端口 18765 启动后，第二次运行旧启动器会再次启动 Uvicorn，打印 WinError 10048，但 PowerShell 退出码为 0。现在启动前检查 `/health`：健康的 LearnNote 实例会复用并重新打开工作台；非 LearnNote 占用端口会在启动依赖前给出明确错误和备用端口。后端异常退出码现在会传回启动脚本。
2. **首页识别链接没有把网址带进表单。** `/api/source/normalize` 返回 `source.normalized_url`，旧前端却读取不存在的 `source.url`，浏览器表单实际显示 `undefined`。现在按 API 契约读取 `normalized_url`，并更新前端缓存键。
3. **公开视频预检会扫描站点整页源码。** 对没有扩展候选的 YouTube 页面，预检调用整页源码扫描；实测这条路径会持续占用后端 CPU，导致 `/health` 超时。已将 yt-dlp 优先站点改为跳过该源码扫描，并显示“可由 yt-dlp 按页面地址解析，可以直接开始任务”；登录和 DRM 限制仍如实交给任务结果处理。
4. **文档导入与视频 AI 选项混在一个表单里。** 选中 PDF/Markdown/TXT/HTML 后，旧表单仍显示视频总结选项和“生成笔记”按钮。现在文档模式隐藏视频处理选项；未选文件时提交按钮禁用并提示“先选择文件”，选中文档后显示“导入并阅读资料”。视频文件仍保留字幕、总结和图文处理选项。
5. **首次配置流程的 UI 回归不应依赖真实模型。** `workspace-ux-acceptance.cjs` 原先没有模拟模型连接 API，导致无 Key 测试等待真实连接结果。现在测试使用内存响应，不提交或保存 Key。

- 测试进程没有配置模型 Key；模型状态为 `llm_model_configured=false`。公开视频测试使用 `yt-dlp --ignore-config`，未读取浏览器 Cookie、登录态或私人资料。字幕源是公开 YouTube 视频 `aircAruvnKk`，不代表整站成功率。
