# 产品基线与参考整合 · 2026-09-07

## 用户定位

面向懂一点计算机、愿意配置模型和控制处理策略的学习者。清晰意味着层次明确、反馈可解释、常用能力可发现，不意味着隐藏功能或把设置压成几个字段。v0.1.55 是本轮功能回归基线；0.2.x 的数据完整性修复和独立修订功能继续保留。

## 指定参考与证据范围

- BiliNote 官方仓库：https://github.com/JefferyHcool/BiliNote 。公开 README 列出了风格/格式配置、多模态、历史版本、原片跳转、模型和转写配置、RAG 问答与可展开工作区。
- Cetle 官网：https://api.cetle.cn/ 。官网展示了视频信息、字幕时间轴、总结、追问、闪卡、测验、导图和工具箱。
- 阿哔视频总结商店页：https://chromewebstore.google.com/detail/adaadldikfegncbkmlmnkbdpkkogcnkb 。商店链接回 Cetle 官网，属于同一产品的分发入口；不是第三套独立产品。商店描述包含多风格总结、字幕定位、保存和学习工具。

以上是公开文档与展示界面的核对，不代表已经登录或付费实测第三方产品。官网和商店的版本/即将发布描述并不完全一致，不把营销文案视为性能保证。借鉴交互和功能组织，代码与本地数据架构仍属于 LearnNote；不复制第三方账号、付费额度、品牌或隐私模式。

## 0.2.x 的具体退步

| 基线能力 | 问题 | 本轮处理 |
|---|---|---|
| 常驻 AI 助教 | 被降成工具菜单里的单次提问 | 恢复常驻入口和对话侧栏，展示来源、模型、历史和引用 |
| 多分区设置 | 原有转写、风格、格式、资源、外观控制不够可见 | 新建六个设置分区，使用真实参数和持久化接口 |
| 创建任务 | 空白欢迎页过大，工作状态不足；创建后的页面参数引用还有错误 | 新首页展示创建、模式、运行环境和最近笔记；修复作用域错误 |
| 阅读控制 | 缺少大纲、专注布局和历史回看 | 恢复大纲/结构导图、专注模式和关联版本入口 |
| 扩展自主性 | 有速记和提问，但缺少直接风格控制和保存操作 | 增加风格、格式、额外要求、载入客户端偏好和 Markdown/SRT 导出 |
| 视觉层次 | 纸感留白过多，图标和工作台身份弱 | 统一 SVG 图标、信息分组、状态区与较紧凑的阅读卡片 |

## 实现边界

- 视频 AI 问答使用已有后端的任务上下文、历史对话和引用；无模型时如实显示本地摘录。当前文档问答仍是当前文档内的原文检索，不冒充生成式 RAG。
- “大纲 / 导图”根据已存在的标题结构生成，属于结构导航，不声称进行了语义概念推断。
- 已有课程、复习卡、OCR、片段、个人补充、修订稿导出和诊断工具保留。
- 远程 ASR 仍复用当前服务地址和 Key，界面明确说明这一限制；不伪造尚不存在的独立转写账号系统。
- 首次引导不强制隐藏专业选项；可见状态与按需说明帮助用户作决定。
- 默认不录屏、不常驻注入页面、不自动向远程服务发送学习内容。用户触发任务后才按已选路由处理。

## 验证

新增 product-workspace-acceptance.cjs 覆盖常驻助教、六个设置分区、参数保存、回答与个人补充、大纲、窄屏布局。视频问答另验证真实后端历史回读和来源引用，模型调用使用本机失败模拟以避免消耗真实额度。扩展保留现有回归并补充风格覆盖与毫秒级 SRT 测试；真实 Edge 扩展 smoke 覆盖侧栏交接、MP4、HLS、播放器接口、iframe 和学习平台模拟页。

功能验收与真实模型笔记质量分开报告。不能因为界面齐全或示例成功，就宣布所有路线图功能和学习效果已经完成。

当前入口的运行时样式单独限制为 1800 行；历史回归样式单独限制为 23000 行并由发布目录检查保证不进入桌面包。避免用历史测试资产的体积代替实际运行时预算。


### 本轮结果

- 后端 452 项测试通过；桌面 25 项测试通过，包含设置/任务路由回归。
- 原有脚本与扩展回归保留，新增扩展风格覆盖、字幕毫秒时间和总结时间点测试。
- 实际 0.2.2 Windows EXE 通过工作台、设置、助教、统一工具和扩展唤起设置的集成检查。
- 对比截图使用隔离演示数据。视频问答验证了后端历史和引用回读；远程模型请求以本机失败模拟替代，未消耗真实模型额度。
- UI 分别展示本地转写组件可用性、模型选择和运行状态，不把安装了运行组件称为模型权重已经下载完成。
