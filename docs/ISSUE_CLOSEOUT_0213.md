## 浏览器插件与 B 站

- 扩展版本更新为 `0.2.13`，缓存查询参数同步更新。
- Edge 真实扩展冒烟通过：Service Worker、后端心跳、MP4、HLS、POST 播放接口、通用播放器、Blob iframe、超星模拟页、Side Panel 交接和下载任务均通过。
- 冒烟夹具明确选择“保存字幕原文”，因此不会把没有模型 Key 的隔离后端误判成插件失败。
- B 站 DOM 字幕兜底只接受字幕叶节点，排除菜单/按钮/设置容器、百分比值及原声翻译控件；background 与后端再次过滤历史污染文本。
- 已打开截图中的 B 站视频 `BV1Kp3t6HEbb`。该视频当前公开播放器接口返回 `need_login_subtitle=true`、字幕数量为 0，因此本次结果应显示“需要登录态/未取得正文”，不能把画面中的可见控件文本当字幕。真实登录态字幕提取仍需用户在已登录浏览器中点一次扩展授权后验收。

## 仍需用户环境确认

1. 在已登录的 Chrome/Edge 中允许当前 B 站站点权限，播放几秒后确认原文预览只有实际字幕；拒绝/撤销/重新授权各走一遍。
2. 用至少 30 页中英文混排样例实际打开 Word/WPS，并对 PDF 做文本提取和逐页渲染；检查缺字、图片、长链接、表格、公式和分页。
3. 对旧课程、已评分卡片、未归属卡片做一次真实副本迁移/恢复矩阵；确认重复执行不增加来源或 FSRS 记录。
4. `v0.2.13` 已于 2026-09-17 以 tag 正式发布；Release draft 恢复演练和 Windows 签名凭据仍是 #134/#55 的后续验收条件，不再作为“是否正式发布”的候选措辞。当前公开资产若未签名，仍必须明确标为未签名。
