# 0.2.9 本地候选版验收

本轮基于 `5225587` 修复 2026-09-13 验收报告中的问题，客户端版本 0.2.9，扩展保持 0.2.8。用户已确认将扩展提交 Google 审核，本轮不修改 `extension/` 内容、不重新提交审核、不发布 GitHub Latest。

## 已修复

- 更新按钮接入编辑保护；未保存设置阻止更新，重复点击不启动第二次安装。
- 更新元数据和已校验安装包状态跨重启保留；关闭自动检查后不查询远程；手动检查仍可用。
- 回退保护嵌套数据目录及其祖先路径；正常启动、失败回退与健康检查均保留端口。
- 安装前重新核对已保存的包校验值；普通浏览器使用一次性凭证调用本机桌面控制器，不能提交任意可执行文件路径。服务器模式不开放安装接口。
- 范围字幕只裁剪一次；原网页回看增加原片起点，视觉路径也只使用范围内字幕。
- 时间戳只用于候选来源定位。原文匹配与待复核释义分开，矛盾量值进入生成质量检查，旧映射不会沿用未经核对的支持标记。
- UI 验收服务器支持新增的 i18n.js；发布脚本按客户端版本生成安装器，独立校验随包扩展版本。

## 验证

- 后端全量 568 项通过；桌面 44 项通过；脚本 60 项通过。
- 更新按钮的桌面桥接和普通浏览器路径、未保存设置保护、一次性凭证和拒绝任意路径均有行为测试。
- Windows 测试实际执行提取出的回退函数，恢复模拟程序文件并保留 `app/storage/notes` 内的笔记；没有对用户数据执行回退。
- 产品工作区、统一工作区、阅读工作流、全局助手和核心输出浏览器验收通过。

## 边界

本轮不会因此关闭全部路线图 Epic。商店审核结果由 Google 决定；签名、公证和真实平台兼容性仍以独立证据为准。词句支持检查采取保守策略，不声称自动判断课程本身的真伪。候选包仅供本地验收，真正发布前仍需候选安装器覆盖升级与发布流水线验收。
