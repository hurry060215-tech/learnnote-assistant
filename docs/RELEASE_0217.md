# LearnNote v0.2.17

## 本次更新

- 独立资料每页加载 100 条，标题搜索覆盖完整资料库。刷新保留已加载页数、焦点与展开状态，来源链接和学习空间仍可打开当前页之外的资料。
- 任务列表一次读取摘要，打开资料时再获取详情。单纯进度更新不再反复读取正文、删除并重建搜索与证据索引，减少大量任务时的磁盘和数据库开销。
- 资料目录和字幕读取不再等待其他任务的搜索索引写入；Windows 文件读取、替换和删除仍互斥，任务取消、重试及恢复保留原有事务保护。
- 任务恢复通过进程所有权区分暂停任务与已退出的进程，避免重复领取、孤立队首阻塞和观察中的任务恢复后无人执行。文字任务与媒体任务分别调度；重试响应晚到时不再把用户从其他页面拉回。
- Windows 媒体子进程在启动前纳入所属进程组，成功、失败、取消或超时后清理整个进程树。
- 更新有已知安全问题的图像、PDF、证书、文件锁和构建依赖：Pillow 13.0.0、pypdf 6.21.2、certifi 2026.10.19、filelock 4.2.1、setuptools 84.1.0，并同步源码安装约束与 Windows 构建锁定版本。
- 已保存观众观点超过 500 条时可继续按页浏览，保留筛选、选择与清除边界。翻页不抓取更多评论，不自动发送给模型；观众观点不代表课程事实、完整评论或统计共识。
- 目录跳转的二至四级标题避开当前固定工具栏与辅助条，保留已有阅读间距和外观。
- 播放跟随按未被固定控件遮挡的正文区域定位：已可见内容保持原位，被遮挡或移出可见区时才调整，过长目标保留开头可读；仍需用户启用跟随。

## 版本、发布与安装

本次源码的客户端与随包浏览器扩展均为 0.2.17。正式发布要求最终提交的门禁、打包、新安装及 0.2.16 → 0.2.17 覆盖升级检查、上传后回下载校验通过。新增资料库分页、来源跳转、学习空间成员和延迟重试响应也在实际安装客户端中验收。源码测试、浏览器截图与历史安装记录不能替代本次安装包验收。现有安装不会因为 main 更新而自动获得修复，需安装对应发布包并核对实际运行版本。

Windows 安装包为 LearnNote-Setup-x64.exe，便携包为 LearnNote-Windows-x64.zip。核对 SHA256SUMS.txt 与 LearnNote-Build-Source.json 中的资产和提交；保留现有本机资料、个人修改及模型配置，升级前建议备份。GitHub 发布不会自动提交 Chrome Web Store，商店版本独立审核。

首次更新索引结构前保留数据库备份；任务与证据、全文搜索和内容版本记录在同一事务中更新。若外部工具在原地改写文件且刻意保留原文件大小与时间戳，可手动重建索引。备份恢复不等于允许新版数据库直接降级，详见[架构审查与验证记录](ARCHITECTURE_REVIEW_20261023.md)。

## 验证边界与平台范围

本次修复覆盖任务调度恢复、索引更新、资料浏览与阅读定位，不证明特定真实客户视频故障已解决，也不证明真实模型语义质量、完整来源覆盖或全部开放 issue 已完成。现有安全诊断仍只展示允许的已有记录；当前运行版本不代表历史任务版本，缺失请求总数、用量与费用保持未知。

长字幕首次可读延迟仍存在跨运行波动：历史 180 分钟合成字幕测试曾超过字幕就绪后 5 秒的可读门禁；后续完整 80 样本门禁通过，仍不代表该波动已消除。具体瓶颈尚未确定，不能据此承诺真实长视频的固定处理时间。

真实模型质量、四小时真实视频、Word/WPS 原生布局、完整浏览器权限/商店安装及全部平台验收仍未全部完成。Windows 未配置 Authenticode 凭据时为未签名包；macOS 未签名、未公证构建仍属预览。已有 macOS arm64 原生迁移与快照回退证据范围有限，不证明新版数据库可直接降级或凭据可迁移；Linux 源码后端测试与容器构建不等于 NAS 实际运行或性能验收。具体范围见[平台支持矩阵](PLATFORM_SUPPORT.md)、[目录迁移指南](DATA_DIRECTORY_MIGRATION.md)和[原生快照回退记录](QA_NATIVE_VERSION_ROLLBACK.md)。

## 维护者发布方式

在 Desktop Release 中填写 release_tag=v0.2.17 与已审阅、CI 通过的完整 40 位 release_commit。工作流要求使用不可变、已公开的 0.2.16 安装包作为升级基线，并核对唯一安装资产的 SHA256 后才运行升级检查；旧版 0.2.16 诊断仍明确使用 0.2.15 基线。

工作流只构建指定提交，在完整门禁、打包和安装升级检查后创建缺失标签；已有标签若指向不同提交则失败，不覆盖。随后通过草稿上传、回下载校验再公开。acceptance_only 诊断不会创建标签或发布版本；历史 0.2.16 和 0.2.15 标签、资产及版本记录保持不变。
