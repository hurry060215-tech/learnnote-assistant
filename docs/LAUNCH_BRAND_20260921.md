# 一键打开工作台与品牌图标

本次为 v0.2.14 之后的源码变更，不覆盖已发布二进制，不代表 Chrome 商店已更新。

## 行为

- 点击打开工作台后，按钮进入忙碌状态；重复点击合并到同一次请求。
- 未启动时调用已注册的 learnnote:// 协议，等待约 45 秒；期间不反复闪回离线提示。
- 连接后优先使用受配对令牌保护的原生窗口聚焦接口；令牌因服务重启失效时只重新配对一次。
- 没有原生窗口的服务保留网页工作台回退，复用既有标签页，不覆盖下载页。
- 超时/无法发起启动显示安装或浏览器确认提示，用户可主动重试，不静默自动重启。
- 桌面端重复启动也先尝试唤回现有窗口，再回退网页。

## 初次安装条件

必须先安装客户端以注册协议。插件不能直接执行任意本地程序，不能替用户绕过浏览器确认。便携/源码使用者可以先手动运行客户端。本次没有修改用户机器的注册表、安装目录、模型设置或真实资料。

## Logo

保留“书页 + 播放 + 笔记”的产品识别，改为深墨绿、鼠尾草绿和暖纸白；扩大书脊留白，16px 去掉细小笔记线。程序化生成 16/32/48/128/256/512 PNG 及多尺寸 ICO，插件、网页、官网和桌面打包使用同一图标源。未更改整体页面布局。

## 验证边界

使用受控前端夹具验证冷启动状态、等待、配对、聚焦和回退；使用桌面单元测试验证循环地址限制和窗口唤回。界面预览是实际 HTML/CSS 在模拟连接状态下的渲染，不是用户 Chrome 实机协议确认的证据。真实未安装、允许/取消协议确认及安装版冷启动仍需实机核对。

本地验证：桌面测试 47 项、品牌资产测试 3 项、扩展全部 Node 测试、网页全部 Node 测试、stage audit、架构边界和 i18n 资源检查通过。连接状态截图及 Logo 预览保存在 `build/launch-brand-preview`；该目录中的扩展 ZIP 是未发布预览包，不覆盖正式 v0.2.14。
