# LearnNote v0.2.20

PDF 安全更新：pypdf 从 6.21.2 更新至 6.21.4，修复缺少 trailer 的交叉引用表死循环及重复页面资源导致的内存放大。问题属于拒绝服务；本次不宣称存在代码执行或数据泄露。

PDF 上传在端点读取文件和等待资料库锁之前进行非阻塞准入，最多同时处理两个请求；忙碌时返回 429 并提示重试。PDF 工作使用独立线程额度，避免占用同步健康检查的默认线程池；请求取消后仍保留准入，直到已有工作结束。此限制不替代 HTTP 服务器的上传传输限制。

PDF 文本导入、预检和已存原文解析使用独立进程：单文件最大 32 MiB，最多两个并行解析进程，30 秒墙钟期限，1 GiB 进程内存上限；POSIX 另有 25 秒 CPU 期限。超限、崩溃或无效结果明确失败并回收子进程。证据上传仍保留 20 MiB 限制。PDF 密码、500 页、500 万字限制和原有页锚点保留。资料、配置和原文不迁移。

发布须完成最终源码 Windows 新安装、上一正式发布版覆盖升级、实际安装功能验收、上传资产重新下载及校验。本说明不代替这些验收证据。macOS 无签名凭据时仅提供工作流中的未签名预览，不宣称正式签名发布。

该隔离仅覆盖 pypdf 文本解析，fitz/OCR、模型质量和复杂公式识别仍按现有边界处理。内存或时间预算可能拒绝复杂但有效的 PDF；请拆分或重新导出后重试。
