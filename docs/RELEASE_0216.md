# LearnNote v0.2.16

## 本次更新

- 安全诊断先预览再保存：Markdown、JSON 与支持包共用仅保留允许类别和数值的报告，预览与保存的字节一致，不自动上传或发送。标题、原文、笔记、网址、路径、凭据和账户/设备标识不进入报告；未记录的历史版本、请求总数、用量和费用保持未知。
- 改善已保存字幕的文字总结重试，保留有限的分段来源检查记录；修正有限的字面等价误报，仍保留无依据名称、数量和内容的拦截。来源检查不等于语义或事实核验。
- 将原文取样与生成草稿明确区分，可定位并查看字幕上下文；保留旧提纲资料，普通总结不预设内容体裁。
- 修复平板设置宽度、手机操作标签换行与渐进正文阅读连续性，避免过期列表刷新丢弃已接收任务。
- 保留显式预览的数据目录迁移：停止旧进程后复制校验，最后切换配置；不移动凭据或自动降级数据库。

## 版本、发布与安装

本次源码的客户端与随包浏览器扩展均为 0.2.16。版本说明不代表发布或安装完成：同提交门禁、打包、安装及覆盖升级检查、上传后回下载校验完成前，本版本仍是待发布候选。现有安装不会因为 main 更新而自动获得修复，需安装对应发布包并核对实际运行版本。

Windows 安装包为 LearnNote-Setup-x64.exe，便携包为 LearnNote-Windows-x64.zip。核对 SHA256SUMS.txt 与 LearnNote-Build-Source.json 中的资产和提交；本机资料、个人修改及模型配置继续保留，升级前建议备份。GitHub 发布不会自动提交 Chrome Web Store，商店版本独立审核。

## 验证边界与平台范围

诊断用于定位已有记录，不是完整模型请求台账；阶段区间可能重叠，不相加或补造缺失耗时。当前运行版本不代表历史任务版本。自动化和合成字幕覆盖不证明某个真实视频故障已经解决，也不证明真实课程质量、阶段时延或全部开放 issue 已完成。

已有 macOS arm64 未签名原生证据覆盖有限的退出、数据目录复制/校验、配置切换与重启；旧版回退依赖恢复升级前快照，新版编辑另存保留，不证明旧程序兼容新版数据库。Linux 证据是源码后端测试，容器构建不等于 NAS 实际运行或性能验收。具体证据及限制见[平台支持矩阵](PLATFORM_SUPPORT.md)、[目录迁移指南](DATA_DIRECTORY_MIGRATION.md)和[原生快照回退记录](QA_NATIVE_VERSION_ROLLBACK.md)。这些历史证据不替代本次 0.2.16 安装包的发布门禁。

真实模型质量、四小时真实视频、Word/WPS 原生布局、完整浏览器权限/商店安装及全部平台验收仍未全部完成。Windows 未配置 Authenticode 凭据时为未签名包；macOS 未签名、未公证构建仍属预览。macOS x64、原生设置桥接/文件夹对话框、凭据迁移及扩展配对等未验范围以支持矩阵为准。不承诺秒提取、固定速度或全部事实正确。

## 维护者发布方式

在 Desktop Release 中填写 release_tag=v0.2.16 与已审阅、CI 通过的完整 40 位 release_commit。工作流只构建该提交，在完整门禁、打包和安装升级检查后创建缺失标签；已有标签若指向不同提交则失败，不覆盖。随后通过草稿上传、回下载校验再公开。无需改写 0.2.15 标签、资产或版本记录。
