# 中英文 claim 投影验收

新增 backend/tests/test_claim_semantic_cases.py：20 段独立编写的中英文来源，分别检查直接引用、实质矛盾但有时间定位、明确推断和无关陈述，共 80 次投影断言。类别包括实体、数量、小数、因果方向、步骤顺序、否定、比例、温度、比较和条件。

修复了基准实际暴露的问题：

- 小数中的句点不再截断整条结论。
- 比例/时间属于来源正文时不被当作引用标记删除。
- 否定句中的肯定子串不能标为直接支持；只有完整句子或分句引用可以跳过人工复核。
- 代码块不当作自然语言结论投影。

边界：这是一组来源映射与保守分类测试，不是模型语义蕴含的准确率评估。合法释义仍可以保留定位并等待核对，不会被自动伪装为已验证原话；真实课程及复杂释义质量仍需单独验收。旧的 53 个规则基准只作为 smoke，不作为 53 个独立语义样本宣传。
