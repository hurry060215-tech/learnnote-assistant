# LearnNote v0.2.21

修复 v0.2.20 在 macOS PDF 解析进程退出时的竞态：系统内存计数可能先消失，退出状态稍后才可见。现在仅对此情形在剩余总期限内等待最多 100 毫秒确认退出；存活且无法监控的进程仍明确失败。进程组清理出错时也会尝试有界子进程回收，并保留原始错误。

继续使用 pypdf 6.21.4，保留 30 秒总期限、内存预算、500 页和 500 万字限制。既有资料、原文、设置不迁移；扩展版本保持 0.2.20。扫描件 OCR/fitz 仍为独立路径。macOS 内存采样之间可能短暂超出预算。

发布必须完成最终源码检查、Windows 新安装与实际 PDF 工作进程验收、从不可变 v0.2.20 的覆盖升级与资料保留、安装后功能验收及上传资产重新下载校验。本说明不代替实际验收结果。无签名凭据的 macOS 构建仅为未签名预览，不宣称签名或公证发布。
