## 改动

- 默认工作台的批注区会显示失效锚点，允许编辑、重新选择当前正文、修复引用或删除。只编辑批注文字会保留旧 anchor revision，不会静默把旧引用标成新出处。
- 默认工作台和复习视图在显示卡片答案前提供可跳过的自我解释步骤。选择记录后只保存一次本地 `self_assessment` 活动，不保存回答文本，也不发送给模型。
- 学习计划页显示近 14 天阅读、作答、自我解释、复习计数和本地卡片掌握分布；待复习卡片仍逐张显示对应证据出处。
- 新增 `/api/study/backup` 和 `/api/study/backup/restore`，备份包含卡片、评分历史、原始活动事件、计划 IANA timezone、个人批注和用户编辑版本。restore 会校验 FSRS/备份版本、记录数量和内容 hash，再做幂等合并；已有评分、同 ID 批注和同来源编辑不会被覆盖。最大备份大小为 100 MB。
- 两个工作台都提供学习备份的导出与导入入口，恢复需要用户选文件并确认。

学习备份不包含源 PDF/视频/字幕、资料库 SQLite 索引、课程学习空间与其自定义练习、社区观点或模型连接凭据；这些数据仍需通过各自已有的导出和本地数据恢复路径还原。原始来源需先回到本机，个人批注才能重新显示并回源。

## 连续验收

新增隔离 TestClient 集成测试使用临时数据目录，在 FastAPI HTTP 层执行：

1. 导入并阅读 Markdown 资料，选择含正文的 evidence anchor。
2. 生成并确认 evidence-backed 卡片，确认 quiz queue 不返回答案正文。
3. 打开出处，记录作答、自我解释活动和“重来”评分。
4. 修改个人版资料、添加引用原文的个人批注，重导入相同资料后检查批注仍挂在相同内容哈希上。
5. 导出学习备份；切换到空学习数据目录；恢复后检查 Asia/Shanghai、编辑稿、批注、错题和评分历史均保留。
6. 重复导入同一备份，确认没有重复评分/活动/批注，且之后修改的本地批注与编辑不会被旧备份覆盖。
7. 将 FSRS 算法篡改为未知版本，确认恢复返回 422 且已恢复数据保持不变。

这条连续路径真实调用本地 HTTP API；输入是构造的 Markdown，无登录资料、远程模型或云服务。

另有隔离的 Playwright 浏览器验收：Windows / Edge，首个浏览器 context 请求 `Asia/Tokyo`，学习设置的初始建议值必须等于浏览器实际报告的时区；随后手动选择与建议不同的计划时区。测试不修改 Windows 时区，也不会伪造浏览器 Intl 结果。从设置和构造 Markdown 导入开始，连续完成全文阅读、课程筛选、生成并确认复习卡、键盘输入自我解释、查看原文出处、评分、导出备份、清空隔离学习库后从设置页恢复备份。恢复后 12 张卡片、1 条评分和手选计划时区均保留。随后用另一个浏览器 context 请求不同的时区重开应用，计划仍保持手选值。课程选择、自我解释、来源打开、评分、计划保存、备份导出/恢复均走键盘激活。若 CI runner 忽略 Playwright 时区请求，验收仍检查该 runner 自己的 Intl 时区与自动建议一致，并且保存值不同且重开后保留。

## 公开视频字幕的测验质量探针

对 Stanford CS224N Spring 2024 Lecture 1 的无登录英文自动字幕做了离线探针。课程页把 Spring 2024 YouTube 系列标为公开材料；使用缓存 VTT，SHA-256 `ed348109b402b9ddf489886053ef560d7ba7cf8ded8efcdeb4226878d2389962`，解析出 3,322 个定时字幕段，没有保存或提交字幕正文。

固定抽样点为 7、14、21、28、35、42、49、56、63、70 分钟；每个点在接下来的 90 秒内选择首个 35–220 字符、非零时长字幕（优先选择带句末标点的段）。原有抽取规则十个样本都会生成通用问题，答案直接是字幕片段；十个都不构成可独立作答的完整题目。新增门禁后，字幕片段至少需持续 4 秒、包含不少于 40 个字符的完整标点句，并能匹配定义/关系题型才可生成。相同十个样本现为 0 张卡；对完整 3,322 段独立运行候选生成也为 0 张卡。对应回归验证不完整字幕被拒、完整定义生成具体问题并保留原 evidence ID。

这说明目前引擎会宁可不从孤立自动字幕段出题，也不展示低质量残句。它没有验证真实模型笔记的语义题目质量；要从视频稳定生成有用问题，仍需把笔记中的完整结论连回其字幕/画面 anchors，并配人工标注正负例（#129/#141）。该报告不是“0%/100% 准确率”。

复习页与阅读页均在 390/768/1440px 视口检查。复习卡宽度分别为 296/553/1054px；阅读器宽度分别为 302/584/715px；三个尺寸均无横向溢出，浏览器无页面异常。代码对比度为 10.9989:1。平板截图曾发现笔记布局落在窄导航栏下方；已修正 681–900px 的网格布局，并加入宽度回归门禁。后台使用独立 `build/study-expanded10-data` 目录和 18777 端口，无用户资料、Cookie 或模型凭据。
